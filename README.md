# UP Service — демонстрационная версия

Адаптация сайта по UP_Service_TZ_site.pdf. Цвета #101010 / #1C1C1C / #F5CE27 / #FFFFFF.

## Реализация
Сервер Sites/Vinext: worker/index.ts, worker/up-api.ts, worker/up-pages.ts. Данные: Cloudflare D1, схема db/schema.ts, миграции drizzle/. Интерфейс: public/index.html, public/up.css, public/up.js. Административная панель: /admin; доступ только владельцу через ChatGPT, UP_ADMIN_EMAIL хранится в настройках Sites. Локальная самостоятельная версия: up-service/server.mjs, Node 22.13+, SQLite.

## Деморежим
Форма сохраняет только обезличенную тестовую заявку. Введённые имя, телефон, автомобиль и комментарий отбрасываются на сервере. Временные условия: базовое ТО 4000 ₽, лимит 5 л, доплата 700 ₽/л; три примера автомобилей. Это не утверждённое коммерческое предложение.

## Требует данных владельца
Реальный телефон и график, логотип и фотографии, утверждённые условия ТО, прайс, отзывы с источниками, реквизиты и политика, получатель Telegram/CRM и номер Метрики. Telegram, CRM и аналитика в деморежиме не отправляют данные. Не отключать демонстрационную маркировку без утверждения этих пунктов.

## Проверки
Локальный сервер: node test.mjs из up-service/. Собранный Worker проверен с D1: страницы/ресурсы, калькулятор, закрытая админка, сохранение и идемпотентность демозаявки.
