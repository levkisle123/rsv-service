# RSV Service — искусство заботы

Адаптивный сайт автосервиса RSV Service в Саратове.

**Открыть сайт:** https://rsv-service-reimagined.neatjoy19.chatgpt.site/

## Запуск локально

Готовая статическая версия находится в `dist/`. Сборка и установка зависимостей не нужны.

```sh
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Для Node.js можно использовать любой статический HTTP-сервер.

## Структура

- `dist/index.html` — страница и форма записи.
- `dist/cinematic.css` — стили и адаптивность.
- `dist/cinematic.js` — меню, этапы, анимации и запись.
- `dist/assets/` — изображения, шрифты и лицензии.
- `DESIGN.md` — визуальная система.
- `ART-DIRECTION.md` — описание изображений и промпты.

## Запись

Форма подготавливает письмо в почтовой программе посетителя. Для отправки посетитель должен подтвердить отправку в ней. Автоматической отправки и интеграции CRM нет.

## Изображения и библиотеки

Художественные изображения автомобиля и турбины созданы с помощью ImageGen. Реальный кадр мастерской обозначен на странице. Использованы официальные Hugeicons Stroke Rounded, Manrope и Onest; лицензии библиотек сохранены в `dist/assets/`.
